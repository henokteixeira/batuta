# Henok owns the rules, and the code is the truth

2026-10-24

The grill had become a substitute for Henok's own decisions, and spec documents and glossary entries were piling up as context for agents. Now a business rule or a product decision without a documented source comes from Henok: the Definer asks, writes down his answer, and labels no ticket, however small, until he has confirmed its rule in one sentence. Technical questions still carry the Definer's recommendation. The rule lives on the ticket until the merge, and after it the code is the source of truth. Separate specs are gone, ADRs stay, and `CONTEXT.md` gets an entry only when Henok asks for one.
